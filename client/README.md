# Product Management Admin Panel

This project is a simple admin panel for managing products in an online store.

## Features

* View products
* Search products
* Filter products by price
* Add new products
* Edit products
* Delete products
* Pagination
* Manage products using the backend API
* URL parameters for search and filters

## Technologies

* React
* Vite
* React Router
* Axios
* CSS Modules

## How to Run

First, install the project dependencies:

```bash
npm install
```

Then run the project:

```bash
npm run dev
```

The project will run on the local development server.

## Project Structure

The project is divided into different parts such as:

* `components` - reusable components
* `pages` - application pages
* `services` - API requests
* `layouts` - page layouts
* `assets` - images and other assets
